# Start Day Skill

Prepares the development environment, sets up today's work log, and generates a morning brief from calendar, Slack, Zoom transcripts, and email.

## Steps

### Step 1: Load configuration

Read `assets/startday_config.json`. It provides:

- `aws_auth_instructions` — placeholder text describing how the user authenticates (e.g. which `aws sso login` command to run, any post-login script). If it still contains the `<get AWS authentication process>` placeholder, ask the user how they authenticate for AWS, walk them through running the command themselves, then offer to save the commands back into `assets/startday_config.json` for future runs.
- `work_log_dir` — absolute or `~`-relative path to the directory containing daily log files (`YYYY-MM-DD.md`).
- `meetings_dir` — directory where meeting transcript summaries are filed.
- `context_file` — optional path to a `CONTEXT.md`-style file with ongoing project context. Skip if blank.
- `watched_slack_channels` — flat list of channel names (without `#`) to summarize in the overnight Slack section. If empty, ask the user which channels to watch and offer to save them back.
- `watched_branch_patterns` — list of git branch globs (e.g. `myusername/*`) to check for yesterday's commits in the recap. If empty, ask the user which branches/patterns to watch and offer to save them back.

If a required value is missing or still a placeholder, ask the user before proceeding — do not guess. When the user provides a value, write it back to `assets/startday_config.json` so future runs skip the prompt.

Also read `assets/user_info.json` if present (injected by skill-vault at install time; contains `email`, `github_username`, `jira_team_name`). Use `github_username` as the commit-author filter in Step 4.

### Step 2: Authenticate

Follow `aws_auth_instructions`. If it is a placeholder, ask the user to run their `aws sso login` command themselves (suggest `! aws sso login` so the output lands in the session), then run any post-login script they specify. Skip this step entirely if the user doesn't use AWS.

### Step 3: Set up today's work log

- Determine today's date (YYYY-MM-DD, user's local timezone).
- Check if `<work_log_dir>/YYYY-MM-DD.md` exists.
- If not, create from the template below.
- Identify the previous workday (if today is Monday, previous workday is Friday).

**Template:**

```markdown
# YYYY-MM-DD (Day of Week)

## Yesterday (Day MM/DD)
- (To be filled in)

## Today's Priority


## Work Done


## Morning Brief
<!-- Generated by /startday -->

## Technical Notes


## Blockers / Needs Clarification


## End of Day Summary

```

### Step 4: Generate yesterday recap

- Read the previous workday's log from `<work_log_dir>`.
- Extract 3–5 bullets from its `## Work Done` and `## Technical Notes` sections.
- For each pattern in `watched_branch_patterns`, check git for commits authored yesterday by the user (use `git log --since=yesterday --until=today --author=<github_username or email from user_info.json>` on matching branches).
- Write the combined recap into today's `## Yesterday` section.

### Step 5: Morning Brief — Google Calendar

Use `mcp__claude_ai_Google_Calendar__list_events` to fetch today's events. Format each as a todo checkbox with local time. Note `(Zoom)` if a Zoom link is present. Append under `## Morning Brief` → `### Today's Meetings`.

```markdown
### Today's Meetings
- [ ] 10:00 AM — Team sync (Zoom)
- [ ] 2:00 PM — 1:1
```

### Step 6: Morning Brief — Overnight Slack

Use `mcp__claude_ai_Slack__slack_search_public_and_private` (or `mcp__claude_ai_Glean__search` with `app:slack` if Glean is available) to search the past 12 hours for messages in the channels listed in `watched_slack_channels`.

Summarize 3–5 high-signal threads and call out any mentions of the user. Append under `## Morning Brief` → `### Overnight Slack`.

```markdown
### Overnight Slack
- #<channel>: <1-line summary> (action needed)
- #<channel>: no critical activity overnight
```

### Step 7: Morning Brief — Zoom Transcripts

Use `mcp__claude_ai_Zoom_for_Claude__recordings_list` to fetch yesterday's recordings. For each recording with a transcript:

- Use `mcp__claude_ai_Zoom_for_Claude__get_meeting_assets` to fetch the transcript.
- Create `<meetings_dir>/YYYY-MM-DD-<meeting-slug>.md` with a 5–10 bullet summary (key points, decisions, action items; call out the user's action items specifically).
- Append the filed path under `## Morning Brief` → `### Zoom Transcripts Filed`.

```markdown
### Zoom Transcripts Filed
- <meetings_dir>/YYYY-MM-DD-team-sync.md (2 action items)
```

### Step 8: Morning Brief — Email Summary

Use `mcp__claude_ai_Gmail__search_threads` with `is:unread newer_than:1d` to fetch unread emails. Skip automated notifications, CI alerts, and mailing lists. Summarize 3–5 action-required items. Append under `## Morning Brief` → `### Email`.

```markdown
### Email
- <sender>: <1-line summary> (needs response)
```

### Step 9: Morning Brief — Jira

Use `mcp__atlassian__search_jira_issues` to fetch issues assigned to the user that are in progress or updated since yesterday. Skip issues that are closed or resolved. Summarize 3–5 action-required items. Append under `## Morning Brief` → `### Jira`.

```markdown
### Jira
- ENG-1234: <1-line summary> (in progress)
- ENG-5678: <1-line summary> (updated yesterday, needs review)
```

### Step 10: Suggest today's priority

- If `context_file` is set and exists, read it.
- Based on pending tasks in today's log plus the context file, suggest one top priority.
- Write it into `## Today's Priority`.

## Output Report

- ✅ Authentication status
- 📝 Today's log: `<work_log_dir>/YYYY-MM-DD.md`
- 📋 Pending tasks carried over
- 📅 Meetings today: N
- 💬 Slack highlights: N threads
- 🎥 Zoom transcripts filed: N
- 📧 Emails needing action: N
- 🎟️ Jira issues in progress or updated: N

## Graceful Degradation

If any MCP is unavailable, skip that section, note it in the output report, and continue. Do not fail the whole skill. Tell the user how to re-enable the connector at https://claude.ai/settings/connectors.

## MCP Dependencies

- `mcp__claude_ai_Zoom_for_Claude__*` — transcripts and recordings
- `mcp__claude_ai_Google_Calendar__*` — today's schedule
- `mcp__claude_ai_Gmail__*` — email summary
- `mcp__claude_ai_Slack__*` (or `mcp__claude_ai_Glean__search` with `app:slack`) — Slack search
- `mcp__atlassian__*` — Jira issues assigned to or updated by the user
